CAD Mouse MK2 - Case Variations
===============================

Based on the 3D files from <https://github.com/sb-ocr/cad-mouse-mk2> (CC-BY-NC-SA-4.0) ... THANK YOU for this project.

The 3D model files in this repo have been recreated from scratch, in [FreeCAD](https://github.com/FreeCAD/FreeCAD/).
The original model sticks to the original step files as closely as possible.

The purpose of this repo is to collect user variations on the original design.
