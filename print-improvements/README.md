Improvements:

- fix counterbore overhang with bridging.
- replace overhang fillets (z-axis) with 45° chamfers.
- add small notch to hide the seam between layers.

The top shell is the only part which needs supports.
For aesthetic reasons, the part should be printed in the final orientation such that it has a smooth top curve.
You *could* print it upside-down (without support) but that will create a hard seam on the top.
